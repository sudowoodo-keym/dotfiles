| Program | Manager |

 ---

## Setup 

1. Clone the dotfile repository and download the necessary programs.
2. Symlink the folders within the repo and replace the existing default configuration templates after installing intended programs.
`ln -s [PATH/TO/TARGET/FILE] [PATH/TO/SYMLINK]`
